# Honda M-NV: рынок подержанных электромобилей в Украине

Streamlit-дашборд по 22 объявлениям Honda M-NV (15 AUTO.RIA и 7 OLX), опубликованным в период 12–25 сентября 2026 года (14 календарных дней). График показывает цену в зависимости от пробега; объявления сравниваются в одной валюте за раз, цвет обозначает год выпуска, символ — площадку. Три вероятных межплощадочных кросс-поста и одна машина под восстановление сохранены, но исключены из стандартного сравнения. Аналитическое резюме находится в `market_snapshot.md`.

## Запуск локально

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Файлы данных

`data/listings.csv` — одна строка на подтвержденное объявление. Файл содержит `id`, `title`, `year`, `price_usd`, `price_uah` (если показана на площадке), `mileage_km`, `published_date` (ISO YYYY-MM-DD), `city`, `source`, `url`, `evidence`, флаг `duplicate_suspected` и поля о состоянии автомобиля.

`data/metadata.json` фиксирует время сбора, период и статус проверенных источников. Приложение не подставляет синтетические данные: если свежие объявления с подтвержденными датами не найдены, оно показывает понятное сообщение вместо фиктивного графика.

## Обновление

Обновите CSV только проверенными карточками объявлений и обновите `collected_at`, `period` и результаты по источникам в `metadata.json`. Для устойчивого сравнения не смешивайте USD, EUR и UAH: приложение фильтрует цены по валюте и не использует предположительный курс пересчета.

## Развёртывание

Приложение можно развернуть как Python web service на Render, команда сборки `pip install -r requirements.txt`, команда запуска `streamlit run app.py --server.address 0.0.0.0 --server.port $PORT`. Бесплатный инстанс может засыпать после простоя и просыпаться при первом запросе; публичный адрес при этом сохраняется.
